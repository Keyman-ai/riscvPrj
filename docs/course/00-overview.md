# 第 0 课：全景地图 —— 从按下开机键到屏幕出字

> 课程主线：学 RISC-V 架构，riscvPrj 项目是教具。
> 类比约定：**盒 = 寄存器，仓库 = 内存，管理员抽屉 = CSR，门铃 = trap，物业 = OpenSBI**。
> 摸底结果：寄存器/栈帧/BSS 已会；CSR 半懂；特权级/trap/中断/委派空白。

## 0.1 这台机器上有什么（5 样东西）

| 东西 | 是什么 | 对应真实概念 |
|------|--------|--------------|
| 🧑‍🔧 工人 | hart（硬件线程），循环：取指 → 执行 → 下一条 | CPU 核。QEMU `-smp 2` 给了 2 个，我们只用 1 个 |
| 📦 32 个盒子 | x0-x31，工人手边工具 | 通用寄存器。x0 恒零；x2=sp 栈指针；x1=ra 返回地址 |
| 🏬 仓库 | DRAM，门牌 0x80000000 起 128MB | 内存 |
| 🗄️ 管理员抽屉 | CSR，要用 `csrr/csrw` 专门指令开 | 控制状态寄存器：mstatus/mtvec/mie/... |
| 🛎️ 门铃 | trap：强制打断当前工作、跳到指定代码 | 异常 + 中断的统一机制 |

**CSR 与盒子的真正区别**（摸底 Q5 的修正）：不是"核内 vs 通用"，
而是①必须用专门指令访问；②**不同特权级（M/S）能开的抽屉不同**。
第 3 课展开。

### 仓库地图（5 个门牌，全项目都在这张图上）

```
0x0000_1000  QEMU 上电第一跳 (ROM, 只有一条跳转)
0x0200_0000  CLINT   闹钟          ┐
0x0c00_0000  PLIC    门铃总机       ├── MMIO 设备门牌
0x1000_0000  UART    对讲机        ┘
0x8000_0000  DRAM: M4 前直接是内核 / M5 起是物业 OpenSBI (占 2MB)
0x8020_0000  M5 起你的内核
```

MMIO 直觉：外设 = 仓库里的特殊门牌。往 0x10000000 写一个字节 = 对对讲机喊话。
没有"设备专用指令"，只有普通的存/取指令。

## 0.2 时间线（M4 / M5 两条）

```
按开机键
 ① PC=0x1000: QEMU ROM, 一条跳转
 ② M4: → 0x80000000 你的 boot.S
    M5: → 0x80000000 OpenSBI (物业: 水电/委派/SBI 服务台)
        → 0x80200000 你的 boot.S
 ③ boot.S: 清 BSS → 立 sp/gp → 挂门铃总机 mtvec → 进 C
 ④ kernel_main: printf 横幅 → 死循环{收字符, 1ms 报 uptime}
 ⑤ 门铃响(按键/闹钟/坏指令)
    → trap.S: 32 盒抄进仓库 → trap.cpp 处理 → mret/sret 回去
```
