# 第 1 课：32 个盒子的两套名字（寄存器与调用约定）

> 前置：第 0 课全景地图。本课补齐摸底 Q3（ebreak/ecall），并给出
> x0-x31 的完整岗位表 —— 它是第 4 课（trap 为什么要保存 31 个盒子）的地基。

## 1.1 两套名字：工牌号 vs 岗位职称

32 个盒子 = 同一批东西的两套叫法：

| 编号 | ABI 名 | 岗位 |
|------|--------|------|
| x0 | zero | 恒零：写什么读出来都是 0（摸底 Q1） |
| x1 | ra | 返回地址：call 的落点 |
| x2 | sp | 栈指针 |
| x3 | gp | 全局指针（小数据锚点，boot.S 里立的） |
| x4 | tp | 线程指针（M7 调度器会用） |
| x5-x7, x28-x31 | t0-t6 | 临时：随便用，不负责还原 |
| x8, x9 | s0/fp, s1 | 保存：谁用谁先抄仓库 |
| x10-x17 | a0-a7 | 参数/返回值 |
| x18-x27 | s2-s11 | 保存（续） |

- **x 编号给硬件看**：指令编码里寄存器字段只有 5 bit（0-31）
- **ABI 名给程序员看**：岗位职责 = 软件世界约定（调用约定）

## 1.2 三派规矩：a / t / s

| 派系 | 规矩 | 一句话 |
|------|------|--------|
| a 系 | 传参入口：调函数参数放 a0-a7，返回值 a0 | 快递收发室 |
| t 系 | 函数可随意覆盖，不还原 | 打工的 |
| s 系 | 用前抄仓库、返回前恢复 | 自留地 |

调用约定三处复用（同一个约定）：
1. C 函数互调：`printf("hi")` → a0 = 字符串地址
2. OpenSBI → kernel_main：a0=hartid, a1=dtb（第 7 课"信封"）
3. 你 → SBI：a7=扩展 ID, a6=功能 ID, a0..a5=参数（sbi.cpp 就是把
   这几个盒子摆好再 ecall）

## 1.3 ebreak 与 ecall（摸底 Q3 补课）

| 指令 | 语义 | trap 后 scause | 项目实证 |
|------|------|----------------|----------|
| ebreak | 故意触发断点："到这儿了，暂停" | 3 | main.cpp 'b' 命令 |
| ecall | 故意提需求："请上层办事" | 8(U提)/9(S提)/11(M提) | sbi_set_timer 内部 |

一句话：**ebreak = 我要被调试，ecall = 我要提需求**。
两者都触发布铃（trap），硬件响铃行为第 4 课逐条讲。

## 1.4 第 4 课的钩子

问：门铃响起时，工人手里的 32 个盒子是谁的责任？
答案预告：门铃一响硬件**只**动两个东西（pc 和一个状态位），
其余 31 个盒子 + 4 个抽屉的责任全在**我们**（trap.S）——
因为硬件不知道闯进来的是谁，t 系可以不管，**s 系一个都不能丢**。
（更保险的做法：31 个全存 —— 项目就是这么干的。）
