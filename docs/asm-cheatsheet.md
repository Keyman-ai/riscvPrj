# 汇编小词典（常用指令速查，随学习进度增长）

> 读法约定：`盒子` = 寄存器（x0~x31，别名 t/a/s/ra/sp），`仓库` = 内存。
> 例：`addi a0, a0, 1` → "a0 = a0 + 1"（add + immediate 立即数）

## 算术
| 指令 | 人话 | 例子 |
|------|------|------|
| `add rd, rs1, rs2` | rd = rs1 + rs2 | `add t0, t1, t2` |
| `addi rd, rs, 数字` | rd = rs + 数字 | `addi sp, sp, -32` |
| `sub rd, rs1, rs2` | rd = rs1 - rs2 | |
| `mul rd, rs1, rs2` | rd = rs1 × rs2 | `mul a0, a0, a0` |
| `div rd, rs1, rs2` | rd = rs1 ÷ rs2 | |

> 带 `w` 后缀（`addiw`/`mulw`）= 32 位运算（int），不带 = 64 位（long）。
> `addiw`/`mulw` 结果会符号扩展成 64 位。

## 移位
| 指令 | 人话 | 例子 |
|------|------|------|
| `slli rd, rs, 数字` | rd = rs 左移 n 位（×2ⁿ） | `slli a0, a0, 3` = ×8 |
| `srli rd, rs, 数字` | rd = rs 逻辑右移 n 位（÷2ⁿ） | |

## 常量
| 指令 | 人话 | 例子 |
|------|------|------|
| `li rd, 小数字` | 往盒子里放个小数字（伪指令） | `li a5, 10` |
| `lui rd, 高20位` | 大数字：先装高 20 位 | `lui a4, 0x10000` → a4 = 0x10000000 |
| `mv rd, rs` | rd = rs（复制盒子，伪指令） | `mv a5, a0` |

## 访存（仓库 ↔ 盒子）
| 指令 | 人话 | 例子 |
|------|------|------|
| `lb / lbu` | 取 1 字节（u=无符号） | `lbu a5, 5(a4)` |
| `lw / lwu` | 取 4 字节 | |
| `ld` | 取 8 字节 | `ld a5, 0(a0)` |
| `sb` | 存 1 字节 | `sb a0, 0(a4)` |
| `sw` | 存 4 字节 | |
| `sd` | 存 8 字节 | `sd ra, 24(sp)` |

> `5(a4)` = "以 a4 里的数为门牌，偏移 5"。地址 = 基准 + 偏移。

## 位运算
| 指令 | 人话 | 例子 |
|------|------|------|
| `andi rd, rs, 数字` | rd = rs & 数字（按位与，常用来看某一位） | `andi a5, a5, 32` 只看 bit5 |
| `ori rd, rs, 数字` | rd = rs \| 数字 | |
| `xori rd, rs, 数字` | rd = rs ^ 数字 | |

## 跳转（分支）
| 指令 | 人话 | 例子 |
|------|------|------|
| `beq rs1, rs2, 标号` | 相等就跳 | `beq a0, a5, 地址` |
| `bne rs1, rs2, 标号` | 不相等就跳 | |
| `blt / bge` | 小于 / 大于等于（有符号）就跳 | |
| `beqz rs, 标号` | rs == 0 就跳（= beq rs, x0） | `beqz a5, 地址` ← while 循环 |
| `bnez rs, 标号` | rs != 0 就跳 | |
| `j 标号` | 无条件跳 | |
| `jal rd, 标号` | 跳 + 把返回地址存进 rd（函数调用） | |
| `ret` | 返回（= jalr x0, 0(ra)） | |

> 标号/地址 = "跳去第几行"，objdump 会用箭头标出来，看方向就行。

## 读汇编三步法
1. **看右边人话**（指令 + 盒子），数字那列（机器码）先无视
2. **从后往前读操作数**：`add t0, t1, t2` = 用 t1、t2，结果放 t0
3. **找跳转**：标号往上跳 = 循环，往下跳 = if/else 分支
